#  Fitness & Workout Tracker

Závěrečný projekt ve 4. ročníku střední školy. Cílem je vytvořit moderní mobilní aplikaci pro komplexní sledování tréninků, posilování, osobních rekordů a porovnávání výkonů s ostatními uživateli.

##  O projektu

Tato aplikace slouží k efektivnímu záznamu cvičení, správě tréninkových plánů a sledování progresu uživatele v čase. Je navržena s důrazem na čistý a intuitivní uživatelský zážitek (UX) a rychlé ovládání během samotného tréninku v posilovně. Kromě offline záznamu nabízí i komunitní porovnání silových výkonů v populárních cvicích.

##  Technologie

Projekt je vyvíjen cross-platformově pomocí moderních nástrojů:
* **[Flutter](https://flutter.dev/)** – UI framework pro iOS i Android
* **Dart** – programovací jazyk
* **SQLite / Drift** – lokální databáze pro rychlý a spolehlivý offline-first provoz
* **Firebase / Supabase** – backend pro správu uživatelů a globálních žebříčků

##  Hlavní plánované funkce

- [ ] **Správa tréninků:** Vytváření a úprava vlastních tréninkových plánů a šablon.
- [ ] **Aktivní tréninkový režim:** Zaznamenávání vah, opakování, sérií a času odpočinku přímo při cvičení.
- [ ] **Historie a statistiky:** Přehled předchozích tréninků, grafy progresu a sledování výkonnosti.
- [ ] **Databáze cviků:** Seznam cviků s popisy/kategoriemi a možností přidávání vlastních.
- [ ] **Osobní rekordy a žebříčky:** Automatické sledování PR (např. na Bench Press, Mrtvý tah) a porovnávání výsledků s ostatními uživateli aplikace.
